# TillFlow × Mara House single-page website

## Direction
Build a refined one-page narrative where Mara House introduces the hospitality experience, then TillFlow’s product UI, payments, operations, and engineering progressively take focus. The page will use warm editorial restaurant styling above and a restrained near-black technical palette below, with one muted green confirmation accent and one subtle clay accent.

## Build
- Establish shared design tokens for the two connected identities, serif/sans typography, spacing, radii, borders, shadows, transitions, and responsive containers.
- Add a single links configuration with empty demo, GitHub, and documentation URLs; related buttons will render only when configured.
- Create the full requested component set and reusable UI primitives.
- Build convincing static concept interfaces for POS, floor plan, orders, M-Pesa confirmation, operations, multi-tenant structure, architecture, engineering, and transaction flow.
- Clearly label all illustrative figures and conceptual views; use only masked phone data.
- Add subtle status and flow animations with reduced-motion support, plus a clean mobile navigation.
- Keep the architecture diagram readable via contained horizontal scrolling on small screens.
- Add route-specific metadata and remove placeholder branding.

## Validation
- Check the desktop and mobile layouts in the running preview.
- Verify anchors, menu behavior, payment replay, responsive diagrams, hidden empty-link buttons, and the absence of page-level horizontal overflow.
- Review build, runtime, console, and network signals before completion.

## Technical details
- Frontend only using React, TanStack Start, Tailwind CSS v4, semantic CSS variables, and inline HTML/CSS/SVG diagrams.
- No backend, authentication, persistence, external API calls, invented URLs, testimonials, logos, or production claims.
